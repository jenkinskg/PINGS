# Simple PDF Reader
Free forever. No ads, trials, subscriptions, login, analytics, or internet permission.
Android 6 or newer. Open multiple PDFs with filename tabs; pinch or use +/- to zoom, drag to pan, double tap to fit, and use Previous/Next to change pages. Each tab remembers its page and zoom while open. Open files using Android's document picker. Password protected PDFs are not supported.

## Download
Download Simple-PDF-Reader-v1.0.apk from the repository release named Simple PDF Reader 1.0.
Allow installation from your browser when Android asks.

## Build
Java 17, Android SDK 35, Gradle 8.9: run gradle -p SimplePdfReader assembleDebug.
GitHub Actions builds and publishes an installable debug-signed APK.
The first version has not been tested on physical hardware.
